# 智声流式交互系统：知识库演示资料

> 文档性质：**本地演示测试资料**，仅用于验证上传、审核、检索、引用和流式问答功能。
> 
> 发布单位：智声项目组（演示环境）  
> 版本：v1.0  
> 发布日期：2026-09-15  
> 建议有效期：2027-09-15  
> 文档编号：DEMO-KB-VOICE-001

## 一、项目目标

智声流式交互系统用于把语音输入、资料检索、大模型增量回答和语音播报连接为一条实时交互链路。系统的核心目标不是一次性生成整段答案，而是在保证回答可追溯的前提下，尽早向用户返回第一段可播放的内容。

系统面对两类场景：

1. **资料问答**：用户询问已授权资料中的具体事实，系统检索资料片段，并在回答中显示引用依据。
2. **实时语音交互**：用户按住或点击麦克风说话，系统完成识别、回答与播报；用户可随时停止当前回答并开始下一轮提问。

## 二、演示环境的组成

演示环境采用以下组件：

| 组件 | 演示用途 | 说明 |
| --- | --- | --- |
| Spring Boot | 用户登录、短期票据、权限与业务接口 | 端口为 18080 |
| Python FastAPI Gateway | WebSocket 会话、事件排序、任务取消 | 端口为 18081 |
| RAG Service | 文档切片、BGE-M3 向量检索与引用返回 | 端口为 18082 |
| FunASR | 中文语音识别 | 语音输入不可用时可改用文字提问 |
| DeepSeek | 增量文本生成 | 以 `llm.delta` 形式返回文本片段 |
| 讯飞在线 TTS | 流式 PCM 音频合成 | 演示发音人使用 `x4_xiaoyan` |
| Vue 前端 | 实时对话、知识库、管理中心和系统观察页面 | 默认开发端口为 8081 |

## 三、实时交互规则

一次浏览器连接对应一个 `sessionId`。同一个会话可以连续进行多轮提问；每一次提问都会创建独立的 `turnId`。

同一轮问答的处理顺序为：

`用户输入 → 资料检索 → DeepSeek 增量回答 → 语义分段 → 讯飞语音合成 → 浏览器播放`

系统会为实时事件分配递增的 `sequence`，用于识别重复或乱序消息。每段可朗读文本拥有 `segmentSequence`；每个音频块拥有 `chunkSequence`。

当用户点击“停止”时，前端立即停止播放器，并发送 `turn.interrupt`。网关必须取消该轮的生成任务、待合成片段和待发送音频。已被取消轮次之后到达的文本、音频或引用事件均应被丢弃，不能进入下一轮回答。

## 四、资料问答与引用规则

只有满足以下条件的资料可以进入默认检索：

1. 已完成审核并发布；
2. 未超过有效期；
3. 当前用户拥有查看权限；
4. 资料未被下架或替代。

系统向大模型提供少量相关资料片段，并为每个片段分配引用标识，例如 `C001`、`C002`。模型回答资料事实时，应基于这些片段；前端通过引用标识显示资料名称、版本、来源和片段位置。

如果没有检索到可靠资料，系统应明确说明“当前资料库中没有可确认的依据”。但对于“你好”“你能做什么”等普通闲聊，系统可以直接正常回复，不应因为没有资料而拒答。

## 五、可用于检索测试的明确事实

以下事实用于验证向量检索是否正确，答案应能在本资料中找到：

1. 智声流式交互系统的 RAG 服务端口是 **18082**。
2. Python 实时网关端口是 **18081**。
3. Spring Boot 业务服务端口是 **18080**。
4. 演示使用的中文向量模型是 **BGE-M3**。
5. 演示使用的讯飞发音人参数是 **x4_xiaoyan**。
6. 用户打断当前回答时发送的事件名称是 **turn.interrupt**。
7. 被取消轮次的迟到文本和音频必须被丢弃，不能与新问题混在一起。
8. 普通闲聊在没有资料命中的情况下允许由大模型直接回答。

## 六、推荐现场提问

上传并发布本资料后，可以在“实时语音”页面依次提问：

- “这个系统的 RAG 服务运行在哪个端口？”
- “演示使用什么向量模型？”
- “用户想停止当前回答时，系统会发送什么事件？”
- “为什么取消后的旧音频不能继续播放？”
- “这个系统的讯飞发音人参数是什么？”

每次回答应显示本资料作为引用来源。推荐在系统开始播报后点击“停止”，再立即输入：“Python 网关端口是多少？” 用于观察旧轮次是否被正确取消。

## 七、验收标准

本资料的演示验收条件如下：

1. 管理员能够上传本文件，并使其经历草稿、审核和发布状态。
2. 发布后，在检索预览中输入“RAG 服务端口”能够召回本资料片段。
3. 实时文字问答能够流式显示答案，并显示本资料的引用。
4. 若语音服务已启动，回答开始后可听到讯飞语音播报。
5. 在播报中点击停止，页面不再继续显示或播放该轮后续内容。
6. 再发起新问题后，新旧两轮内容在页面中分别保存，不互相混合。
