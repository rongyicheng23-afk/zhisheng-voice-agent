## 8. 常见故障处理

### 8.1 公网地址打不开
处理步骤：

```bash
/Users/rongyicheng/Desktop/layout-voice-factory/deploy/stop-local-publish.sh
/Users/rongyicheng/Desktop/layout-voice-factory/deploy/start-local-publish.sh
```

然后重新执行：

```bash
/Users/rongyicheng/Desktop/layout-voice-factory/deploy/status-local-publish.sh
```

然后重新执行：

```bash
/Users/rongyicheng/Desktop/layout-voice-factory/deploy/status-local-publish.sh
```

确认：
- `NATAPP: RUNNING`
- `公网地址: http://voice.baconboat.cn`
- `公网状态: HEALTHY`

如果 NATAPP 在线但仍打不开：
- 检查 Cloudflare 里的 `voice.baconboat.cn` 是否仍是 `CNAME -> c419aef4a1659869.natapp.cc`
- 并确认该记录为 `仅限 DNS`
- 如果日志里出现 `errorCode: 1202` 或“当前已欠费”，先去 NATAPP 后台充值，再重启整套服务

### 8.2 页面能打开，但登录或历史报错
先看 MySQL 是否正常：

```bash
/Users/rongyicheng/Desktop/layout-voice-factory/deploy/status-local-publish.sh
```

确认：
- `MySQL: RUNNING`
- `PORT 3306: LISTENING`

### 8.3 录音转文字不可用
检查：
- `FunASR HTTP`
- `FunASR WebSocket`

### 8.4 文字转语音不可用
检查：
- `TTS`

### 8.5 声纹对比不可用
检查：
- `Voiceprint`

### 8.6 智能纪要无法生成
同时检查：
- `MySQL`
- `MinIO`
- `FunASR HTTP`
- `Spring Boot`
