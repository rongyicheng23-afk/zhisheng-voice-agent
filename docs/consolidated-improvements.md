### DER 用法

评估环境需要 NumPy/SciPy。项目本机测试环境已有这两项依赖，未升级模型环境。

```bash
python services/evaluation/diarization.py annotations.json
python -m unittest services.evaluation.test_diarization -v
```

输入是单场录音的 `durationSeconds`、人工 `reference` 和系统 `hypothesis`，后两项均为 `{start,end,speaker}` 列表，时间单位为秒。标签仅用匿名 ID；不要把模型自己的结果当作人工参考。

计算口径参考 [pyannote.metrics 官方指标说明](https://pyannote.github.io/pyannote-metrics/reference.html)：最佳一对一映射、collar=0、保留重叠；本实现为受限区间评估器，不是完整 pyannote 封装，不支持额外 UEM 区域或非零 collar。单元测试是构造标注，不是实际会议质量报告。
